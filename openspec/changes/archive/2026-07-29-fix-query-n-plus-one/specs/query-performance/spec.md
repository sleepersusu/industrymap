## ADDED Requirements

### Requirement: 對外查詢的資料庫往返次數與結果筆數脫鉤

對外查詢端點送出的 SQL 筆數 MUST NOT 隨回傳筆數線性成長。同一支查詢在不同扇出
（回傳筆數）之下，送出的 SQL 筆數 SHALL 相同。

此要求 MUST 有可執行的驗證守住，且該驗證 SHALL 以「兩種扇出的筆數相同」表達，
MUST NOT 以「筆數不得超過某常數」表達——後者會隨無關的實作調整而失敗，
反覆誤報會讓人停用它，於是真的長回線性成長時反而沒人發現。

#### Scenario: 扇出增加不改變往返次數
- **WHEN** 同一支對外查詢分別在小扇出與大扇出的資料下執行
- **THEN** 兩次送出的 SQL 筆數 SHALL 相同

#### Scenario: 關聯載入不得逐筆進行
- **WHEN** 查詢結果的每一筆都需要讀取它所指向的實體（公司、品類節點）
- **THEN** 這些實體 SHALL 以一次查詢一併取得，MUST NOT 每筆各查一次

#### Scenario: 圖走訪不得逐節點往返
- **WHEN** 查詢需要沿組成關係走訪多層
- **THEN** 走訪 SHALL 由資料庫一次完成，MUST NOT 每經過一個節點就往返一次
